================================================================================
  NAVHUB DASHBOARD — OVERVIEW & WHAT HAS BEEN BUILT
================================================================================

NavHub is a unified command-center dashboard for Navchetna's suite of products.
It is built with Next.js 14 (App Router), TypeScript, Tailwind CSS, and
Phosphor Icons. It supports dark mode (default), light mode, and system mode.

--------------------------------------------------------------------------------
  TECH STACK
--------------------------------------------------------------------------------
  - Framework   : Next.js 14 (App Router, 'use client' pages)
  - Language    : TypeScript + TSX
  - Styling     : Tailwind CSS + CSS custom properties (design tokens)
  - Icons       : @phosphor-icons/react
  - Fonts       : Inter (Google Fonts)
  - Theme       : Dark / Light / System (via ThemeProvider context)
  - Logo        : Group 80.png (white-on-transparent, inverted in light mode)

  DASHBOARD HOME  (/dashboard)
--------------------------------------------------------------------------------
  - Welcome hero with user's name
  - Global search bar (Ctrl+K)

--------------------------------------------------------------------------------
  ANALYTICS  (/dashboard/analytics/*)
--------------------------------------------------------------------------------
  Tab bar: Overview | Usage | Performance | Health | Caching |
           Rate limits | Cost | Logs | Insights

  Overview tab:
    - Filter bar (Add filter, Live refresh, Date range picker)
    - 4 stat cards: Total Requests, Total Visits, Cache Hit Rate, Data Transfer
    - Requests over time chart (area chart, no-data empty state)
    - Device type donut chart
    - Requests by country (no-data state)
    - Status codes card (no-data empty state with illustration)
    - Top paths / hosts / client IPs (3-column grid)
    - Top browsers / OS / user agents (3-column grid)
    - Top HTTP versions / cache statuses / origin status codes (3-column grid)

  Performance tab (Web Analytics):
    - Feature description + Enable button
    - Feature cards carousel (6 cards: Real-time insights, Custom events,
      Privacy, First-party, Easy integration, Fast script)
    - Demo dashboard (blurred/faded): metric tabs, area chart, analytics panels
      for Pages, Referrers, Countries, Devices, OS, Events, Flags

  Traffic tab (Usage):
    - 4 stat cards: Total Requests, Unique Visitors, Bandwidth Used, Error Rate
    - Requests & unique visitors over time (dual area chart)
    - Bandwidth over time chart
    - Errors over time chart
    - Requests by HTTP method (donut + bar chart)
    - Requests by protocol (donut + bar chart)
    - Requests by content type (bar chart)
    - Top referrers / countries / bandwidth by host
    - Top status codes / paths / client IPs

  Date Range Picker (shared across analytics):
    - Preset list: Last 1h, 6h, 24h, 7d, 30d, 3mo, 12mo, MTD, YTD
    - Custom calendar with range selection (start/end highlight, hover preview)
    - Apply / Cancel buttons

  Other tabs (Health, Caching, Rate limits, Cost, Logs, Insights):
    - Pages exist at their routes but show placeholder / no-data states
